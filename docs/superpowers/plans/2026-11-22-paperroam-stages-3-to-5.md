# PaperRoam 第三至第五阶段实施计划

> 按阶段实现，用测试、真实请求和固定样本记录验收结果。

**目标** 完成有出处的全文取证、用户确认的 SQLite 记忆，以及检索和记忆对照实验。

**设计** Python 控制来源、工具、预算和引用。DeepSeek 保留单路与多路判断，也能为全文任务提出一次针对缺口的补搜。默认阅读清单入口保持兼容。记忆通过同一交互会话或显式启用读取，持久化用于用户确认的字段。

- [x] 全文取证：指定版本、本地 PDF 和索引关联开放全文；用页码和原文记录；全文不可用时按摘要交付；补搜最多一次。
- [x] 任务工具与记忆：本地计算、有限重试、交互入口；SQLite 版本历史、重复处理、确认后写入。模型提取候选与实际写入分开。
- [x] 对照实验：固定论文、问题、相关段落和模型；测 BM25、向量融合、重排、上下文、记忆开关。记录 API 实际 Token、延迟、费用和局限。
- [x] 验证：回归测试、真实 PDF、交互写入更新、实跑对照；做整体验收和代码审查。
